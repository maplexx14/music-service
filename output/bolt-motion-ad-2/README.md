# Bolt — второй референс

Адаптация `C:/Users/maplex/Downloads/spotify motion graphics ad(1).mp4` для Bolt на русском языке. Сохранены вылетающие слова с размытием, поворот вступительного текста, переход с тёмного фона на фирменный, знак с последующим раскрытием логотипа и перечисление любимой музыки.

`bolt-motion-ru.mp4` — 1920 × 1080, 16:9; `bolt-motion-ru-tiktok.mp4` — 1080 × 1920, 9:16. Обе версии: 10,4 секунды, 60 fps, H.264 / AAC, BT.709. Файлы с суффиксом `-silent` — без звука.

Сценарий: «Вся музыка, которую ты любишь» → «Твои любимые исполнители / группы / плейлисты / треки» → «Вся твоя музыка» → «В любое время» → «Где угодно» → «Без ограничений» → «Включай Bolt».

Использованы актуальный логотип Bolt и шрифт Geologica из проекта. Оригинальная электронная подложка — 150 BPM, переходы озвучены отдельно. Для вертикального видео длинные фразы переразложены с отступами под интерфейс TikTok.

Пересборка из корня проекта: `node output/bolt-motion-ad-2/render.cjs`; вертикальная версия — добавить `--tiktok`. Для ключевых кадров — `--stills`. Требуются Playwright Core, Edge и FFmpeg; пути можно задать через `PLAYWRIGHT_MODULE`, `EDGE_PATH`, `FFMPEG_PATH`.

`preview.html` и `preview-tiktok.html` — локальное превью с воспроизведением и перемоткой. Тексты и анимация находятся в `renderer.js`, звук и экспорт — в `render.cjs`.
