# Bolt — ролик на русском

`bolt-motion-ru.mp4` — горизонтальный ролик со звуком: 1920 × 1080, 16:9, 60 fps, 10,4 секунды, H.264 / AAC, BT.709.

`bolt-motion-ru-tiktok.mp4` — вертикальная версия для TikTok: 1080 × 1920, 9:16, 60 fps, 10,4 секунды. Длинные фразы перенесены на две строки; значимое содержимое расположено с отступами под интерфейс TikTok. Это отдельная композиция.

Добавлен кадр «Без ограничений». Ускорены переходы и появление слов, музыка ускорена со 120 до 150 BPM.

`bolt-motion-ru-silent.mp4` и `bolt-motion-ru-tiktok-silent.mp4` — версии без звука для монтажа.

`preview.html` — локальное превью с воспроизведением и перемоткой. `preview-tiktok.html` открывает вертикальное превью.

Визуальный референс: `C:/Users/maplex/Downloads/spotify motion graphics ad.mp4`. Сохранены крупная типографика, последовательное появление слов, переход с тёмного фона на фирменный, логотип в верхней части и короткие сменяющиеся сообщения. Использованы актуальные логотип и шрифт Geologica из проекта Bolt. Электронная музыка и звуковые акценты созданы программно для этого ролика.

Пересборка: `node output/bolt-motion-ad/render.cjs` из корня проекта; для TikTok добавить `--tiktok`. Требуются Playwright Core, Edge и FFmpeg. Пути можно задать через `PLAYWRIGHT_MODULE`, `EDGE_PATH`, `FFMPEG_PATH`. Для ключевых кадров добавить `--stills`.

Русские тексты и тайминг находятся в `renderer.js`, музыка и параметры экспорта — в `render.cjs`.
