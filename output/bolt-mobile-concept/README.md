# Bolt — мобильный ролик 9:16

`bolt-mobile-9x16.mp4` — 1080 × 1920, **9:16**, 60 fps, **12,1 секунды**, H.264 / AAC, BT.709. `bolt-mobile-9x16-silent.mp4` — тот же монтаж без звука. Просмотр в обычном браузере: `preview.html`. Предыдущая версия сохранена в `bolt-mobile-9x16-before-native-motion.mp4`.

Артисты: **cupsize, madk1d, fortuna812**. Изображения получены из реальной выдачи localhost; названия источников — CUPSIZE, madk1d, FORTUNA 812. Для подписей сохранены названия, указанные пользователем.

Демонстрация снята с настоящей мобильной версии `http://localhost` в браузере с экраном 390 × 844, плотностью 3× и сенсорным вводом. В начале показана главная с CD-проигрывателем; нативный свайп влево переводит её к поиску. Жест проходит в свободной области над корпусом, чтобы не переключать треки на диске. Затем видны мобильный поиск, нижнее меню, мини-плеер и полноэкранный мобильный плеер. Ответы API и интерфейс приложения не подменяются. Для главной использован отдельный временный локальный аккаунт, удаляемый после съёмки; браузер эмулирует режим установленной PWA.

В начале на главной играет **«Юра Юра» / CUPSIZE**: диск вращается, корпус поворачивается в перспективе штатной анимацией приложения. После свайпа на 1,75 секунде показано касание Pause. Далее сохранена исходная демонстрация поиска и полноэкранного плеера на отметке 0:30. На 6,7 секунде касание Play возобновляет воспроизведение; кнопка показывает Pause, звучит реальный фрагмент того же трека, движется прогресс и камера возвращается к общему виду.

Движение корпуса снято с работающего проигрывателя сервиса: `cd-player-playback-tilt`, период 18 секунд и 121 ключевой кадр из `cdPlaybackMotion.js`. Монтаж сохраняет траекторию корпуса из приложения. Часы съёмки включаются до запуска приложения, чтобы GPU и диск продолжали обновлять кадры. Изменение изображения проверяется непосредственно по пикселям области проигрывателя.

Для плавности вступления анимации и GPU снимаются на общей временной отметке каждого кадра. Во время съёмки отключается повторное округление вращения диска через `steps()`. `stabilize-intro.cjs` проверяет все соседние кадры до свайпа и восстанавливает единичные пропущенные GPU-кадры интерполяцией движения. Результаты проверки записаны в `intro.json`: повторяющихся кадров нет.

Протяжка нативного свайпа занимает **250 мс**. Координаты пальца идут по плавной кривой с нулевой скоростью и ускорением на концах; затем экраны доезжают пружиной приложения. Индикатор касания использует ту же траекторию.

| Время | Действие |
| --- | --- |
| 0–1,2 с | Главная: штатный поворот корпуса и вращение играющего диска |
| 1,2–1,45 с | Плавный свайп влево |
| 1,45–1,75 с | Пружинный доезд к поиску |
| 1,75 с | Касание Pause в мини-плеере |
| 1,75–2,0 с | Поиск с треком на паузе |
| 2,0–3,17 с | Мобильный поиск cupsize; текущий трек приостановлен |
| 3,17–4,7 с | Касание «Лучшие», результаты поиска |
| 4,7 с | Касание мини-плеера, открытие приостановленного трека |
| 5,2–6,7 с | Общий вид мобильного плеера и приближение к Play |
| 6,7 с | Единственное касание Play: начинается воспроизведение |
| 6,7–8,2 с | Звук трека, отклик кнопки, движение прогресса, общий вид |
| 8,2–8,6 с | Уход интерфейса |
| 8,6–9,56 с | cupsize, madk1d, fortuna812 |
| 9,56–10,6 с | «В твоём ритме» / «В одно касание» |
| 10,6–12,1 с | Логотип Bolt и короткий финал |

Концовка после демонстрации сокращена с 6,13 до 3,5 секунды. Музыкальное приглушение и вступление реального трека сдвинуты вместе с касанием Play; звук мягко затухает в конце.

Сохранены плавная траектория камеры, постоянное размытие движения, сглаживание текстур и фиолетовое свечение. Мышиный курсор заменён индикаторами касания. На касании Play музыка референса приглушается, вступает фрагмент настоящего потока localhost; затем подложка возвращается.

Исходная запись: `localhost-mobile-demo.mp4`, кадры — `assets/live/`. Новая сцена: `assets/intro/` и `intro.json`. `capture.json` хранит сведения о мобильном устройстве, состояния плеера до и после действия и единственный переход воспроизведения в исходной записи. `assets/intro-track.wav` — звук играющего трека в начальной сцене, `assets/demo-track.wav` — фрагмент после касания Play; `soundtrack-mixed.m4a` — итоговая фонограмма. `storyboard.jpg` — ключевые кадры.

Пересборка из корня проекта:

```powershell
node output/bolt-mobile-concept/capture.cjs
node output/bolt-mobile-concept/capture-intro.cjs
node output/bolt-mobile-concept/stabilize-intro.cjs
node output/bolt-mobile-concept/render.cjs
node output/bolt-mobile-concept/verify.cjs
```

Для проверки кадров добавить `--stills` к `capture.cjs` и `render.cjs`; `capture-intro.cjs --probe` сохраняет главную без записи жеста. Параметры — в `project.json`. Требуются Playwright Core, Edge, FFmpeg, Sharp и работающий локальный `music_backend` в Docker; пути можно задать через `PLAYWRIGHT_MODULE`, `EDGE_PATH`, `FFMPEG_PATH`, `REFERENCE_PATH`, `BOLT_URL`.
