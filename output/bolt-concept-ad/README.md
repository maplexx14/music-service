# Bolt — концепт-ролик интерфейса

Визуальный референс: `C:/Users/maplex/Downloads/Spotify 2.0 Concept 🎶.mp4`.

`bolt-motion-ru.mp4` — 1920 × 1080, 16:9; `bolt-motion-ru-tiktok.mp4` — 1080 × 1920, 9:16. Обе версии: 12,8 секунды, 60 fps, H.264 / AAC, BT.709. Файлы с суффиксом `-silent` — без звука. Превью с перемоткой: `preview.html`, `preview-tiktok.html`.

Сохранена подача референса: тёмный фон со свечением, парящий интерфейс, движение камеры, выбор вкладки, раскрытие карточки, приближение к кнопке, отклик на действие и финальная типографика.

Ролик показывает художественно собранный концепт интерфейса Bolt с существующими функциями: медиатека, персональный поток, избранное. Это не запись действующего приложения. Тексты и демонстрационные данные заложены в сценарии; друзья, комментарии и социальные реакции из референса не рекламируются как функции Bolt.

Логотип, Geologica и фирменные цвета — из проекта. Обложки: Only A Lad из ранее подготовленных материалов и System Of A Down из локального превью проекта. Фонограмма и эффекты созданы программно; музыка показанных артистов не включена.

Пересборка: `node output/bolt-concept-ad/render.cjs`; для TikTok добавить `--tiktok`, для ключевых кадров — `--stills`. Требуются Playwright Core, Edge, FFmpeg; пути задаются через `PLAYWRIGHT_MODULE`, `EDGE_PATH`, `FFMPEG_PATH`. `renderer.js` содержит графику и тайминг, `render.cjs` — звук и экспорт.
