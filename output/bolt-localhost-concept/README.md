# Bolt — ролик с реальным интерфейсом localhost

`bolt-localhost-concept.mp4`: 1920 × 1080, 16:9, 60 fps, 12,733 секунды, H.264 / AAC, BT.709. `bolt-localhost-concept-silent.mp4` — тот же монтаж без звука. `preview.html` — просмотр и перемотка в обычном браузере.

Референс: `C:/Users/maplex/Downloads/Spotify 2.0 Concept 🎶.mp4`. Сохранены последовательность сцен и темп: появление интерфейса в перспективе, выбор вкладки, движение камеры по списку, раскрытие карточки, быстрое приближение к действию, отклик кнопки, уход интерфейса влево, поочерёдное появление слов и аватаров, раскрытие логотипа и финальный текст со свечением. При монтаже добавлены плавная смена двух реальных состояний поиска и свечение вокруг кнопки на нажатие. Зелёное свечение заменено фирменным фиолетовым. Звуковая дорожка взята из предоставленного референса.

Демонстрация снята с `http://localhost/search`: поиск Daft Punk → фильтр «Лучшие» → One More Time → полноэкранный плеер → пауза и возобновление. Использованы реальные ответы API, обложки, кнопки и анимации работающего приложения. Фрагмент доступен в гостевом режиме. Главная, персональные рекомендации и лайки требуют входа и в этот монтаж не включены.

`localhost-demo.mp4` — исходный фрагмент интерфейса. Его кадры находятся в `assets/live/`. Запись сделана с управлением временем JavaScript и нативных анимаций браузера для ровной частоты 60 fps; время аудиоэлемента синхронизируется с кадрами. Звук этого трека в итоговый ролик не добавлялся. `capture.json` хранит адрес, реальные действия, геометрию элементов и проверку успешного воспроизведения. Ответы API и данные аккаунта не подменяются. Файлы исходного приложения не изменяются.

Пересборка из корня проекта:

```powershell
node output/bolt-localhost-concept/capture.cjs
node output/bolt-localhost-concept/render.cjs
```

Для проверки ключевых кадров добавить `--stills` к обоим шагам. `composition.html` содержит покадровое монтажное превью; экспорт запускает его с необходимым доступом к локальным изображениям. `renderer.js` содержит камеру и титры. `storyboard.jpg` — ключевые кадры. `reference-timeline.jpg` — разбор предоставленного референса с таймкодами.

Требуются Playwright Core, Edge, FFmpeg и Sharp. Пути к инструментам можно передать через `PLAYWRIGHT_MODULE`, `EDGE_PATH`, `FFMPEG_PATH`, к референсу — через `REFERENCE_PATH`, адрес локального приложения — через `BOLT_URL`.

Для плавности движения и отклика применён навык [emil-design-eng](C:/Users/maplex/.agents/skills/emil-design-eng/SKILL.md): сильные кривые ускорения, короткий отклик на нажатие, объясняющая анимация и проверка промежуточных кадров.
