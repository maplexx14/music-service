# Bolt — Oingo Boingo / Little Girls

Вертикальный проморолик: **1080 × 1920, 30 fps, 12 секунд**, H.264 / AAC.

- `bolt-little-girls.mp4` — версия с оригинальными звуковыми эффектами на переходах.
- `bolt-little-girls-silent.mp4` — версия без аудиодорожки для монтажа.
- `preview.html` — интерактивное превью графики с перемоткой; открывается локально.
- `01-hook.png`, `02-track.png`, `03-bolt.png` — ключевые кадры.

## Сценарий

| Время | Кадр |
| --- | --- |
| 0–3,5 с | Стилизованный форумный пост: «Как эту песню вообще выпустили?» / «Открыл перевод. Теперь есть вопросы». |
| 3,5–8,4 с | «Да, это песня». Обложка Only A Lad, Little Girls, Oingo Boingo, 1981. |
| 8,4–12 с | «Слушай в» + логотип Bolt, карточка трека, «Ссылка в профиле». |

Это художественная стилизация поста, а не скриншот Reddit. Никакие реальные пользователи, оценки или комментарии не воспроизводятся.

**Фонограмма Oingo Boingo и цитата из текста песни не включены.** Звуковые эффекты созданы программно для этого ролика. Наличие композиции в Bolt принято из задания пользователя; живой каталог не проверялся. Ролик не опубликован.

## Пересборка

`node render.cjs` рендерит кадры в Edge и кодирует их через FFmpeg. Пути к `playwright-core` и FFmpeg можно задать переменными `PLAYWRIGHT_MODULE` и `FFMPEG_PATH`. `node render.cjs --stills` обновляет только ключевые кадры.

Тексты и тайминг находятся в `renderer.js`, звуковые эффекты и настройки экспорта — в `render.cjs`. Исходный код приложения не менялся.
