# Bolt — версия с русскоязычными артистами

`bolt-localhost-concept-ru.mp4` — 1920 × 1080, 60 fps, 12,733 секунды, H.264 / AAC, BT.709. `bolt-localhost-concept-ru-silent.mp4` — версия без звука. `preview.html` открывается в обычном браузере с воспроизведением и перемоткой.

Артисты в титрах: **МОТ, Zivert, ANNA ASTI**. Фотографии и обложки получены из реальной выдачи `http://localhost/search`; изображение МОТа взято с карточки «100% Мот», если она есть в выдаче. Демонстрация снята с localhost: поиск «МОТ» → «Лучшие» → **«Сопрано» / Мот, Ани Лорак** → полноэкранный плеер → пауза и возобновление. Данные и ответы API не подменяются. Исходный фрагмент — `localhost-demo.mp4`, его кадры — `assets/live/`, сведения о записи — `capture.json`.

Исправления плавности:

- Более мягкое появление интерфейса в первые 0,95 секунды.
- Непрерывная скорость камеры на стыках траектории вместо отдельных разгонов и остановок.
- Один режим размытия движения: восемь промежуточных положений камеры и курсора на каждый кадр, без переключения по порогу скорости.
- Усреднение промежуточных изображений на GPU вместо сложения полупрозрачных кадров в Canvas, которое меняло яркость.
- Сглаживание уменьшенных текстур интерфейса с mipmaps, чтобы мелкий текст не мерцал при движении.
- Курсор рисуется отдельно и движется между кадрами плавно. Статичный вид поиска в начале берётся из одного реального кадра записи.

Сохранены монтаж, фиолетовое свечение, приближения, отклик кнопки, финальный логотип и звуковая дорожка из предоставленного референса `Spotify 2.0 Concept 🎶.mp4`.

Пересборка из корня проекта:

```powershell
node output/bolt-localhost-concept-ru/capture.cjs
node output/bolt-localhost-concept-ru/render.cjs
node output/bolt-localhost-concept-ru/verify.cjs
```

Для ключевых кадров добавить `--stills` к первым двум командам. `project.json` задаёт артистов, поисковый запрос и трек. `composition.html` — монтажное превью; `storyboard.jpg` — ключевые кадры. Требуются Playwright Core, Edge, FFmpeg и Sharp; пути можно передать через `PLAYWRIGHT_MODULE`, `EDGE_PATH`, `FFMPEG_PATH`, `REFERENCE_PATH`, `BOLT_URL`.
