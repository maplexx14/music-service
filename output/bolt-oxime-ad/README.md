# Bolt — 3D-ролик по референсу OXIMEFX

[Готовый ролик](bolt-oxime-ru.mp4): 18 секунд, 1920 × 1080, 16:9, 60 fps, H.264 / AAC, BT.709. [Просмотр с управлением](preview.html). [Версия без звука](bolt-oxime-ru-silent.mp4). [Ключевые кадры](storyboard.jpg).

Самостоятельная 3D-анимация для Bolt по композициям и монтажной последовательности `I Made an ad for SPOTIFY!! _ OXIMEFX.mp4`: стол с наушниками и телефоном, вращающийся знак, ленты эквалайзера, винил, слои плейлистов, сфера частиц, звуковой ландшафт, холмы, музыкальные ноты, телефон с обложками, карусель и светлый финал.

Использованы логотип и фиолетовая палитра Bolt. На телефоне — сохранённый экран настоящего плеера из `output/bolt-localhost-current-final/mobile-player.png`. Его изображение внутри 3D-модели статично. Обложки и фотографии артистов взяты из ранее подготовленных материалов проекта. Абстрактные обложки, материалы и все 3D-объекты построены программно. Для белого финала подготовлен вариант логотипа с тёмными буквами.

Фонограмма взята из указанного пользователем видео; в конце добавлено короткое затухание. Она не заменена музыкой артистов, показанных на экране.

Тайминг сцен находится в `project.json`; геометрия, материалы и движение камеры — в `scene.js`; экспорт — в `render.cjs`. Рендер воспроизводит временную отметку каждого из 1080 кадров через Three.js в Edge и передаёт кадры FFmpeg.

Пересборка из корня проекта:

```powershell
node output/bolt-oxime-ad/prepare.cjs
node output/bolt-oxime-ad/render.cjs --stills --draft
node output/bolt-oxime-ad/render.cjs
node output/bolt-oxime-ad/verify.cjs
```

Нужны установленные в этом рабочем окружении Three.js, Sharp, Playwright Core, Edge и FFmpeg. Пути к исполняемым файлам можно задать через `PLAYWRIGHT_MODULE`, `EDGE_PATH` и `FFMPEG_PATH`. `render.cjs` сам запускает временный локальный сервер и закрывает его после рендера. `--draft` меняет разрешение на 1280 × 720; `--stills` сохраняет только ключевые кадры.

`render.json` содержит параметры экспорта и ошибки браузера. `verification.json` фиксирует проверку декодирования и сравнение кадров готового MP4 с исходными изображениями.
