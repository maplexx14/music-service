# Новый дизайн bolt

Откройте `index.html` для просмотра скриншотов компьютера и телефона.

Это снимки настоящего React-приложения, запущенного на локальном Vite-сервере. Данные аккаунта и медиатеки подставляются только инструментом съёмки, через перехват запросов в изолированном браузере. В приложение демонстрационные данные не добавлены. Обложки взяты из ранее сохранённых материалов проекта.

Обновлены общая палитра и элементы управления, главная, поиск, медиатека, страницы коллекций и артистов, настройки, вход и оформление плеера. Выбор CD-плеера в настройках сохраняется.

Проверки: production-сборка, 62 теста плеера, пять основных экранов при 1440×1080 и 390×844, открытие и закрытие полноэкранного плеера. Ошибок JavaScript и горизонтального переполнения на проверенных экранах нет. Проверка интерфейса с демонстрационными данными не проверяет реальный аудиопоток.

Для повторной съёмки запустите Vite на порту 3012 и `node output/bolt-studio-redesign/capture.cjs` из корня проекта.
