# bolt — стиль видео

Референс: локальный ролик `6d747159e20fe708bfc9377280f2f78b.mp4`. Из него взяты почти чёрная основа, полупрозрачные панели, белые основные кнопки и тонкие светящиеся линии. CD-проигрыватель остаётся настоящим существующим компонентом с управлением, перемоткой, очередью и настройкой корпуса.

Главная показывает проигрыватель до начала воспроизведения. После выбора трека на диске появляется его обложка. Панель под проигрывателем открывает полноэкранный плеер. Мини-плеер остаётся на остальных экранах; на главной управление находится под корпусом.

Откройте `index.html` для просмотра компьютера и телефона. Скриншоты сделаны с настоящего локального React-приложения. Демонстрационные данные подставляются только в изолированном браузере скриптом `capture.cjs`; код приложения не содержит этих данных. Снимки `home-empty` показывают состояние без выбранного трека.

Проверены production-сборка, 62 теста плеера, пять основных экранов при 1440×1080 и 390×844, загрузка сцены проигрывателя, открытие полноэкранного плеера с главной и его закрытие. Эти проверки интерфейса не проверяют реальный аудиопоток. Результаты браузерной проверки — в `verification.json`.

Повторная съёмка: Vite на порту 3012, затем `node output/bolt-transit-redesign/capture.cjs` из корня проекта.
