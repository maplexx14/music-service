# Bolt — Агас / Азия — Евразия

Актуальная версия: **`bolt-agas-karaoke-neutral-v2.mp4`**, 15,3 секунды, 1080 × 1920, 30 fps, H.264 / AAC.

В нейтральной версии 2 добавлены фирменные молнии Bolt: фиолетовая заливка, тёмный контур, циановая и розовая обводки из сервиса. Молнии реагируют на смены планов и нажатие воспроизведения. С 13,1 с карточка плавно уменьшается и сдвигается влево; справа появляется PNG с удивлённой мордой того же верблюда и коротким веером молний из загрузчика. Логотип, подпись и адрес сохраняют размер и положение. Текст и AAC-озвучка нейтральной версии 1 сохранены; аудио копируется без перекодирования. Предпросмотр — `preview-neutral-v2.html`, эффекты — `neutral-effects.js`, ключевые кадры — `effects-01-wide.png` – `effects-07-final.png`. Пересборка: `node render-neutral.cjs` (использует сохранённый `bolt-agas-karaoke-neutral.mp4` как источник звука).

Нейтральная версия: PNG-верблюд с прозрачным фоном, новый текст и полностью новая синтезированная озвучка Microsoft Irina Desktop. Сценарий — `neutral-story.json`; караоке синхронизировано по событиям произнесения слов и скорости каждой фразы, тайминги — `neutral-timing.json`. Сохранены пять планов с верблюдом, пузырьки кислорода и финал с записью сервиса. Звуковая дорожка собрана только из шести нейтральных реплик; аудио прежних роликов не используется. Предпросмотр — `preview-neutral.html`, графика с перемоткой — `neutral-preview.html`.

Пересборка исходной нейтральной озвучки и её таймингов:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File narrate-neutral.ps1
node prepare-neutral.cjs
```

Ключевые кадры: `neutral-01-wide.png` – `neutral-06-final.png`. `node render-neutral.cjs --stills` обновляет только кадры.

Версия 7 заменяет векторного верблюда на фотографический PNG с прозрачным фоном во всех пяти планах. Использована фотография из `../camel-photo/camel.jpg`; источник и лицензия указаны в `assets/camel-SOURCE.md`. `camel-photo.js` размещает вырезанного верблюда на прежней сцене и сохраняет движение, смены ракурсов, караоке и финал версии 6. Озвучка копируется из версии 6 без перекодирования. Предпросмотр — `preview-v7.html`, пересборка — `node render-dynamic.cjs`.

Версия 6 улучшает финал: камера плавно приближается к названию, затем к кнопке, удерживает момент нажатия и возвращается к общему виду. Масштаб и вертикальное смещение интерполируются вместе, без скачков. Подсветка нажатия следует за границами кнопки. Логотип, подпись и адрес плавно увеличиваются; подпись не исчезает между планами. С 13,14 с финальная композиция стабильна для чтения ссылки. Озвучка скопирована из версии 5 без перекодирования. Предпросмотр — `preview-v6.html`, пересборка — `node render-dynamic.cjs`.

Версия 5: начало заново смонтировано в пять визуальных планов — общий план на горе, крупная реакция, движение в одну сторону, смена ракурса и крупные пузырьки O₂. Караоке показывает текущую фразу крупным текстом по две строки. В запись сервиса ведёт круговой переход; затем камера приближается к названию и кнопке воспроизведения и возвращается к общему виду. Озвучка скопирована из версии 4 без перекодирования: ускорение и сокращённая пауза сохранены. Предпросмотр — `preview-v5.html`, пересборка — `node render-dynamic.cjs`. `dynamic-scenes.js` содержит монтаж и караоке; `dynamic-preview.html` позволяет перематывать графику по кадрам.

В версии 4 над караоке добавлена векторная анимация: верблюд шагает на каменистую вершину, моргает, двигает ушами и поворачивает голову; на фразе про кислород поднимаются пузырьки O₂. Анимация исчезает к переходу на сервис. Озвучка копируется из версии 3 без повторного кодирования. Предпросмотр — `preview-v4.html`, пересборка — `node render-camel.cjs` поверх сохранённой версии 3. `camel-overlay.js` содержит рисунок и движения; `camel-overlay.html` — поверхность рендера.

В версии 3 пауза между двумя двустишиями сокращена с 0,97 до примерно 0,27 секунды. Из середины тишины одновременно вырезаны 21 кадр и 33 600 аудиосэмплов (0,7 с), поэтому синхронизация караоке сохранена. Предпросмотр версии 3 — `preview-v3.html`. Пересборка: `node shorten-pause.cjs` поверх сохранённой версии 2.

Версия 2 ускорена на 10% с сохранением высоты голоса. Светлая плашка и подпись «без контекста» убраны, размер текста увеличен с 45 до 68 px (длинная строка подгоняется по ширине). Подпись «Уже есть аккаунт? Войти» закрыта цветом поверхности карточки в видеозаписи.

## Монтаж

- 0–1,72 с: гора, шаги верблюда, первая фраза караоке.
- 1,72–3,36 с: крупный план головы, реакция и вторая фраза.
- 3,36–5,58 с: два ракурса с движением верблюда; третья фраза караоке.
- 5,58–7,39 с: пузырьки O₂ и последняя фраза цитаты.
- 7,39–7,74 с: круговой переход на запись сервиса.
- 7,74–15,3 с: запись живой страницы с приближением к названию, кнопке и возвратом к общему виду.

Единственная звуковая дорожка — предоставленный пользователем `ozv.mp3`, ускоренный через `atempo=1.1` с сохранением высоты голоса. Тот же коэффициент применяется к заливке букв, переходу и записи сервиса; исходный файл не изменён. В конце оставлена короткая пауза. Системного TTS, звуков перехода и фонограммы песни в актуальном ролике нет. Звук браузерного плеера при записи был выключен; воспроизведение самого трека проверено по состоянию HTML audio.

## Источник записи и обнаруженная ошибка

Страница: https://boltmusic.lat/track/6b3546a3-8ab0-47a6-8c5e-51735d6c79c1

При записи гостевая страница запрашивала `/api/tracks/undefined`: `GuestTrack` не получал ID из маршрута. В браузере записи этот единственный запрос перенаправлен на публичный `/api/tracks/6b3546a3-8ab0-47a6-8c5e-51735d6c79c1`. Ответ не подменялся выдуманными данными; обложка, карточка и стрим получены с настоящего сервера. Код приложения и сервер не изменялись. До исправления маршрута обычная гостевая ссылка может показывать «Трек не найден».

## Пересборка

Из этой папки:

```powershell
node render-dynamic.cjs
```

Для обновления записи сервиса сначала выполните `node capture-service.cjs`. `node render-dynamic.cjs --stills` обновляет ключевые кадры актуальной версии. Пути к зависимостям рендера можно задать через `PLAYWRIGHT_MODULE`, `FFMPEG_PATH`, `EDGE_PATH`.

Файлы `bolt-agas-asia-eurasia.mp4`, `preview.html`, `render.cjs`, `renderer.js`, `narrate.ps1`, `story.json` и `timeline.json` относятся к предыдущему варианту с системной озвучкой. Они не используются в актуальной сборке.
