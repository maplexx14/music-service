# Проверка приложения в Android-эмуляторе

Дата: 11 ноября 2026. Android 15 / API 35, AVD `bolt_api35`, debug APK 1.9
(versionCode 10). Проверена текущая сборка `frontend/dist` в настоящем WebView;
API, каптча, подтверждение почты, обложки и аудио обращались к рабочему сервису.

Создан отдельный тестовый аккаунт через настоящую регистрацию и письмо
подтверждения. Пройдены выбор жанров и артиста, сохранение предпочтений,
повторный вход и открытие главной. Данные доступа находятся в игнорируемой
папке сборки и в этот отчёт не включены.

## Найденные и исправленные ошибки

| До | После | Зачем |
| --- | --- | --- |
| Диски ожидали загрузки обложек и исчезали при её сбое | Геометрия дисков и анимация появляются независимо от изображения | При принудительном отказе всех обложек видны все три диска |
| FastAPI возвращал массив ошибок регистрации, который обрушал React | Форма показывает строку «Проверьте адрес почты» и остаётся доступной | Проверено настоящим вводом `qa@example` и ответом 422 |
| Ошибка загрузки медиатеки выглядела как отсутствие плейлистов | Сообщение об ошибке и кнопка «Повторить»; ошибочная пустая коллекция не сохраняется в кэш | После повтора появляется уже созданный плейлист |
| Сбой каталога жанров оставлял пустой выбор | Сообщение и повтор запроса | Сохранённый выбор возвращается после восстановления сервиса |
| Подсказки артистов молча исчезали после сбоя | Повтор работает для подсказок по жанрам и для той же поисковой строки | Не требуется менять запрос или заново открывать настройки |
| Экран ошибки зависел от ленивого CSS страницы плейлиста | Собственные отступы, заголовок и кнопка; обработанные ошибки не дублируются тостом | Холодное открытие медиатеки выглядит так же, как последующие |
| Счётчики показывали «1 треков» | Склонение «1 трек / 2 трека / 5 треков» | Исправлены заголовки плейлистов, понравившихся, альбомов и внешних подборок |
| На 320 px лайк выходил за правый край, верхние кнопки перекрывались строкой состояния | Компактные кнопки с областью нажатия 44 px и отступ с учётом `--safe-top` | Все кнопки помещаются на 320, 360 и 412 px |

## Проверенные сценарии

- Регистрация, настоящая каптча, письмо подтверждения, онбординг, выход и
  повторный вход без повторения онбординга; некорректный адрес почты.
- Главная, три диска, отказ загрузки всех обложек, пустая история, сохранение
  состояния после перезагрузки.
- Поиск настоящих треков, переключение источника, быстрые изменения запроса,
  сохранение строки и фильтра при переходах между вкладками; отдельно
  проверены YouTube Music, SoundCloud, Deezer, Spotify и медиатека.
- Пустая медиатека, создание плейлиста с длинным русским названием, добавление
  трека, отображение сохранённого трека, корректное объяснение дубликата.
- Неверная ссылка импорта и закрытие формы; настоящий Android-выбор файла
  и возврат после отмены; форма загрузки без выбранного аудио.
- Настройки жанров и артистов: ошибки HTTP 500, повтор и восстановление;
  отдельный повтор поиска артиста с неизменённой строкой.
- Медиатека без кэша: HTTP 500, ошибка при отключённой сети, повтор после
  восстановления соединения. Сохранённая медиатека допустимо остаётся на
  экране при сбое фонового обновления.
- Страница артиста, ссылки на альбомы, настоящие треки альбома, ошибка холодной
  загрузки альбома и восстановление по кнопке «Повторить».
- Настоящее аудио: запуск, пауза/продолжение, перемотка, следующий/предыдущий
  трек, переключение повтора и случайного порядка, лайк, текст песни.
- Системные медиакнопки Android действительно ставят аудио на паузу и
  возобновляют его; уведомление воспроизведения отображается в шторке.
- Фоновое воспроизведение без CDP: приложение свёрнуто, экран заблокирован.
  Между снимками прошло 304 секунды, аудио продвинулось на 303 секунды и
  перешло с `Numb` на следующий трек. Запуск следующего аудио зафиксирован
  диагностикой с `hidden: true`. [Результат](app/build/reports/ui-audit/background-result.json).
- Android Back: возврат из плейлиста, закрытие диалога добавления перед
  полноэкранным плеером, закрытие плеера с сохранением маршрута.
- Портретные ширины 320, 360 и 412 CSS px: главная, поиск, медиатека,
  понравившиеся, выбор жанров, загрузка; полноэкранный плеер отдельно.
  Горизонтальная компоновка поиска и настроек. Проверены размеры DOM и
  сделаны снимки настоящего экрана эмулятора.

## Проверки исходников и границы результата

Итоговая матрица: **68 успешных проверок, 0 оставшихся падений**.
[Детальные результаты](app/build/reports/ui-audit/final-tests.json) содержат
также причины исключения пяти устаревших записей: проверки до исправления
и неверные ожидания о тёплом кэше, встроенной форме импорта и дубликате трека.
Исходные записи сохранены в локальных отчётах.

Прошли сборка Vite, 133 UI-теста, проверки Android-интеграции, очереди плеера
и касаний, ESLint затронутых файлов. Ранее в этой проверке также успешно
выполнены `testDebugUnitTest`, `lintDebug`, `assembleDebug` оболочки Android.

При повторном изменении размеров программный графический режим эмулятора
дважды завершился с Windows exception `0xc0000005` в
`qemu-system-x86_64.exe`. После перехода на `-gpu host -feature -Vulkan`
проверки главной и узкого плеера завершились. Это зарегистрированный сбой
процесса эмулятора; его первопричина в графическом стеке не установлена.

Полная загрузка аудиофайла на сервер, импорт больших внешних коллекций,
восстановление пароля и изменения 2FA в эту матрицу не входят. Длительная
работа в фоне и ограничения батареи на телефонах производителей требуют
отдельной проверки на соответствующих устройствах.
