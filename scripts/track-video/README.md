# Ролики Bolt по треку

Из корня репозитория

```powershell
npm install
npm run track-video -- "ONDA ANDAR — cachalot"
npm run track-video -- "https://music.youtube.com/watch?v=Zrq71nOI3C4" --start 1:06.815
```

Нужны Node.js 22+, запущенный Bolt, Edge или Chrome и FFmpeg с кодировщиком libx264. Скрипт использует `http://localhost` по умолчанию. Адрес Bolt задаётся через `--bolt-url` или `BOLT_URL`. Для браузера из другого каталога укажите `BROWSER_PATH`, для FFmpeg вне `PATH` — `FFMPEG_PATH`.

Поддерживаются ссылки на отдельные треки Bolt, YouTube, YouTube Music и SoundCloud. По ссылкам Spotify, Яндекс Музыки и Deezer скрипт подбирает запись в каталоге Bolt по названию, исполнителю и длительности. Для поиска по названию можно добавить исполнителя. Скрипт покажет выбранный трек перед записью.

По умолчанию фрагмент начинается примерно на 55% длительности трека. Чтобы выбрать конкретный момент, передайте `--start 66.815` или `--start 1:06.815`. Музыка играет на протяжении всего ролика. После свайпа от CD-плеера к поиску открывается текст из LRCLIB, если он доступен. Синхронный текст подсвечивается по ходу трека. Когда текста нет, полноэкранная обложка показывается около 1,7 секунды. Затем ролик возвращается к первому кадру. Общая длительность составляет около 9,4 секунды с текстом или 8 секунд с обложкой.

MP4 с H.264 и AAC сохраняется в `output/track-videos/` с разрешением 1080 × 1920 и частотой 60 кадров/с. `--output "путь.mp4"` задаёт другое место сохранения. Повторный запуск с тем же выходным путём заменяет файл после успешного рендера.
